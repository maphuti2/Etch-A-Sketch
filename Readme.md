# Etch-A-Sketch

A modern web-based version of the classic Etch-A-Sketch toy! Users can draw on a resizable grid using a variety of colors and tools.

## Features

- **Resizable Grid**: Select the size of the drawing grid (between 1x1 and 100x100).
- **Color Options**:
  - Black
  - Random colors
  - Eraser to clear parts of your drawing
- **Clear Board**: Wipe the entire grid to start fresh.
- **Interactive Drawing**: Click to start drawing and toggle drawing mode with a click.

## Technologies Used

- **HTML5** for structure
- **CSS3** for styling
- **JavaScript** for interactivity
